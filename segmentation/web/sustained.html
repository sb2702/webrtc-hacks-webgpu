Idle

Sustained load windows

Runs each selected pipeline flat out (360p transcode, looping) for a fixed window, with idle gaps in between, so its hardware usage stands out in a system monitor — e.g. macmon or sudo powermetrics --samplers cpu_power,gpu_power,ane_power on macOS, intel_gpu_top / nvtop on Linux, Task Manager on Windows. The banner and the tab title say what is running; the log below records wall-clock times.
